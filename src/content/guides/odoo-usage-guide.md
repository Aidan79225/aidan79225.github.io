Odoo 18 操作流程手冊 — 家庭農場 ERP 三大日常作業：建立產品、開立銷售單、收帳收款。

適用範圍：Odoo 18 社群版 (CE)・繁體中文・銷售 / 發票管理 / 庫存

## 整體流程圖

三項作業有先後順序：要開銷售單，產品必須先存在；要收帳，銷售單必須先開發票。建議依下列順序操作。

① 建立產品（商品資料 / 售價）→ ② 建立銷售單（報價 → 確認 → 出貨）→ ②-b 開立發票（從銷售單產生）→ ③ 收帳收款（登記付款 → 已付款）

> **名詞對照**
> 本手冊的「收帳」＝在 Odoo 中對客戶發票執行「登記付款」，使發票狀態變為「已付款」。社群版沒有完整「會計」模組，收款在**「發票管理（Invoicing）」** App 完成。

## 登入系統

1. **開啟瀏覽器** — 輸入農場網址（例如 `https://farm.你的網域`）。本系統透過 Cloudflare Tunnel 對外，沒有開放對外連接埠。
2. **輸入帳號密碼** — 使用管理員或操作員帳號登入。
3. **進入主選單** — 登入後左上角點「≣」圖示可切換各 App（銷售、發票管理、庫存…）。

> **小撇步：** 找不到功能時，用畫面上方的搜尋列直接輸入關鍵字（如「產品」「報價」），可快速跳轉。

## 作業①：建立產品

路徑：`銷售` → `產品` → `產品` → 新增（或從 `庫存` App 進入，結果相同）

1. **進入產品清單** — 開啟「銷售」App，上方選單點「產品 ▸ 產品」。
2. **按「新增」** — 點左上角「新增」開啟空白產品卡。
3. **填寫產品名稱** — 最上方輸入品名，例如「有機高麗菜（每箱）」。
4. **選擇產品類型** — Odoo 18 的類型為「商品 (Goods)」或「服務 (Service)」。實體農產品選「商品」。若要追蹤庫存數量，勾選「追蹤庫存 / Track Inventory」。
5. **設定售價與成本** — 在「一般資訊」分頁填**銷售價格**（賣給客戶的價格）與**成本**（進貨/生產成本）。
6. **設定稅別與計量單位** — 確認「客戶稅別」與「計量單位（如 箱、公斤、件）」正確。
7. **（建議）填內部參考編號** — 在「一般資訊」分頁的**內部參考 (Internal Reference)** 填料號，方便日後搜尋與盤點。
8. **儲存** — 點上方「☁ 儲存」（雲朵圖示）完成建立。產品即可在銷售單中被選用。

### 必填 / 建議欄位一覽

| 欄位 | 說明 | 必填 |
|------|------|------|
| 產品名稱 | 顯示在銷售單、發票上的品名 | 是 |
| 產品類型 | 商品（實體）或服務 | 是 |
| 銷售價格 | 開銷售單時的預設單價 | 建議 |
| 成本 | 用於毛利計算 | 建議 |
| 客戶稅別 | 開發票時自動帶入稅金 | 建議 |
| 計量單位 | 箱 / 公斤 / 件 等 | 是 |
| 內部參考 | 料號，利於搜尋 | 選填 |
| 產品圖片 | 右上角可上傳照片 | 選填 |

> **小撇步：** 農產品常依規格分開建立（如「高麗菜-小箱」「高麗菜-大箱」），方便分別計價與統計。

## 作業②：建立銷售單

路徑：`銷售` → `訂單` → `報價單` → 新增

流程：A 報價單（草稿）→ B 確認訂單（銷售訂單）→ C 出貨（庫存交貨單）→ D 建立發票（轉作業③）

1. **新增報價單** — 開「銷售」App → 「訂單 ▸ 報價單」→ 新增。
2. **選擇客戶** — 在「客戶」欄選現有客戶；新客戶可直接輸入名稱後點「建立並編輯」。
3. **加入訂單明細** — 在「訂單明細」分頁點「新增一行」，選產品 → 系統自動帶出售價 → 輸入**數量**。重複加入多項產品。
4. **確認金額與稅** — 右下角會即時計算 未稅 / 稅金 / 含稅總計。必要時可改單價或加折扣。
5. **送出報價（選用）** — 點「以電子郵件傳送」把報價寄給客戶確認；或直接進下一步。
6. **確認訂單** — 客戶同意後點「確認」，報價單即轉為正式銷售訂單，產生訂單編號（SO0001…）。
7. **出貨 / 交貨** — 若為實體商品，右上角會出現「交貨」按鈕，點入後按「驗證」完成出貨並扣庫存。
8. **建立發票** — 點「建立發票」→ 選擇「正常發票（全額）」→「建立並檢視發票」。接著進入作業③ 收帳。

> **狀態說明：** 報價單（草稿）尚未成立交易；按下「確認」後才成為銷售訂單，並計入銷售統計。

> **小撇步：** 常態出貨給同一客戶時，可在客戶卡片設定預設付款條件，開單時自動帶入。

## 作業③：收帳（開發票＋收款）

路徑：`發票管理` → `客戶` → `發票`（或直接從銷售單的「建立發票」進入）

流程：A 發票草稿（草稿）→ B 確認 / 過帳（已過帳・待付）→ C 登記付款（選銀行/現金）→ D 已付款（收帳完成）

### 步驟

1. **確認（過帳）發票** — 由銷售單「建立發票」進來後，發票為草稿。核對品項與金額後，點「確認」過帳，狀態變為「已過帳」，付款狀態為「待付款」。系統自動產生發票號碼（INV/2026/…）。
2. **登記付款** — 在已過帳的發票上，點上方「登記付款」按鈕。
3. **填寫收款資訊** — 在彈出視窗選擇：

   | 欄位 | 填法 |
   |------|------|
   | 日記帳 (Journal) | 收到的方式：銀行 或 現金 |
   | 金額 | 預設帶全額；部分收款可改成實收金額 |
   | 付款日期 | 實際收款日 |
   | 備註 / 參考 | 選填，如匯款後五碼 |

4. **建立付款** — 點「建立付款」。發票右上角即出現綠色「已付款」戳記，收帳完成。

### 部分收款 / 多筆對帳

> **分次收款：** 步驟 3 把「金額」改成本次實收即可。發票會顯示「部分付款」，剩餘金額待下次再次「登記付款」。全部收齊後自動轉為「已付款」。

### 查詢未收款（應收帳款）

1. **看哪些還沒收** — 進「發票管理 ▸ 客戶 ▸ 發票」，用篩選器選「待付款」，即列出所有尚未收齊的發票。
2. **客戶對帳單** — 在客戶卡片可檢視該客戶的所有發票與付款紀錄，核對總應收金額。

> **注意：** 「登記付款」只在**已過帳**的發票上才會出現。若還是草稿，請先點「確認」。

## 單據狀態對照表

| 作業 | 狀態 | 意義 | 下一步 |
|------|------|------|--------|
| 銷售單 | 報價單（草稿） | 尚未成立交易 | 確認 |
| 銷售單 | 銷售訂單 | 客戶已確認 | 出貨 / 建立發票 |
| 發票（收帳） | 草稿 | 尚未過帳 | 確認 |
| 發票（收帳） | 已過帳・待付款 | 已成立應收 | 登記付款 |
| 發票（收帳） | 已付款 | 款項收齊 | 完成 |

## 常見問題

### Q：銷售單上找不到我要的產品？

請先完成作業① 建立產品並儲存。產品需存在才能被選用。

### Q：發票上沒有「登記付款」按鈕？

該發票還是「草稿」。先點「確認」過帳，按鈕才會出現。

### Q：客戶只先付訂金怎麼辦？

照常「登記付款」，把金額改成訂金數額。發票會記為部分付款，尾款收齊後自動轉「已付款」。

### Q：開錯發票可以取消嗎？

已過帳的發票不可直接刪除。請使用「退回 / 開立貸項通知單 (Credit Note)」沖銷，以保留帳務軌跡。

### Q：社群版有「會計」App 嗎？

沒有完整會計，但「發票管理」已涵蓋開立客戶發票、登記付款與應收查詢，足以應付日常收帳。
