# 03 · 合約重點清單

> 這份是**簽約前的檢查清單,不是法律意見**。第一份正式合約建議請律師看過一次,
> 之後就能當成自己的範本重複使用。

## 每份合約都要有的條款

- [ ] **雙方資訊**:姓名 / 公司名、統編、地址、聯絡人
- [ ] **工作範圍**:直接引用提案中選定的方案,附上提案作為附件
- [ ] **不包含的項目**:與提案一致
- [ ] **交付物與驗收**:交付什麼、什麼形式、對方幾天內提出意見,逾期視為驗收
- [ ] **時程**:開始日、交付日;對方延遲提供資料或權限時,時程順延
- [ ] **費用與付款**:金額(未稅 / 含稅)、分期比例、付款期限、逾期處理
- [ ] **範圍變更**:追加需求須以書面(email 即可)確認並另行報價
- [ ] **保密**:雙方對彼此的機密資訊保密,期限 {2–3} 年;或另簽 NDA
- [ ] **智慧財產權**:
  - 交付的報告與文件,付清款項後歸客戶
  - 你既有的知識、範本、方法論仍歸你所有,可在其他案子使用
- [ ] **責任上限**:以本合約已收取的費用總額為上限;不對間接損失負責
- [ ] **建議性質**:顧問提供建議,採用與否及執行結果由客戶自行負責
- [ ] **終止**:任一方可提前 {14} 天書面通知終止;已完成的工作按比例計費
- [ ] **獨立承攬**:雙方為承攬關係,非僱傭關係
- [ ] **準據法與管轄法院**:中華民國法律,{台北} 地方法院

## 跟正職有關的額外確認

- [ ] 合約中**不出現**現職公司名稱,不引用任何現職公司的資料或經驗細節
- [ ] 客戶不是現職公司的客戶、供應商或競爭對手
- [ ] 工作時間安排在正職工時以外
- [ ] 已重新讀過自己的僱傭合約:兼職、競業、智慧財產權歸屬等條款

## 收款與稅務備忘

- 個人接案常見的做法是由客戶開立**勞務報酬單**並代扣所得稅,
  金額較高時可能還有二代健保補充保費。
- 案量穩定之後,可以評估成立工作室或公司開立發票。
- 以上規定與門檻會變動,**實際細節請問會計師**。

## 簽約前的最後確認

- [ ] 對方的簽約人有權代表公司簽署
- [ ] 訂金已入帳才開始工作
- [ ] 合約與提案的範圍、金額、時程三者一致
