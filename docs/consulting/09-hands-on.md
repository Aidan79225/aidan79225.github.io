# 09 · 動手參與

顧問也可以動手做,而且常常是**建議真的被執行的關鍵**。報告寫得再好,團隊沒時間或不知道從何下手,最後還是會被放著。

但動手參與有它的陷阱:一不小心就從「顧問」變成「便宜的外包工程師」。這份說明怎麼動手,同時守住顧問的定位。

## 三種動手的方式

| 方式 | 內容 | 適合的時機 | 計價 |
|---|---|---|---|
| **帶著做**(pairing) | 跟內部工程師一起修第一個問題,示範做法,之後由他們接手 | 健檢之後,團隊知道要做什麼但不確定怎麼做 | 按天,設上限 |
| **實作衝刺** | 固定範圍,由我主導完成報告中的某一項(例如 DAG 冪等化、告警重整) | 範圍清楚、團隊人力不足 | 固定價 |
| **兼任架構師 / SRE**(fractional) | 每月固定 {N} 天嵌入團隊,參與設計審查、code review、技術決策 | 團隊還沒有資深的人,或正在招募 | 月費 |

**最自然的路徑**:架構健檢 → 報告中 1–2 項高優先項目用「帶著做」→ 團隊上手後改成陪跑。

## 為什麼值得做

- **建議會被執行。** 客戶看得到成果,推薦也更有說服力。
- **證明你的建議可行。** 動手做過,才知道「工作量 M」是不是真的 M,報告的可信度會提高。
- **收入更穩定。** 健檢是一次性的,動手參與和兼任常常是長期的。
- **保持手感。** 顧問太久沒寫程式,建議會越來越脫離現實。

## 守住定位的原則

1. **永遠跟內部工程師 pair。** 程式碼由他們 own、他們 merge。我寫的每一行,團隊都要有人看懂、能維護。
2. **走他們的流程。** 用他們的 branch、PR、code review、CI,**不直接碰 production**,不繞過任何審核。
3. **知識轉移是交付物。** 每一項實作都要附上:設計說明、runbook、一場 walkthrough。結案時團隊要能不靠我。
4. **最小權限。** 優先用開發 / staging 環境;需要 production 權限時,只要唯讀,或由內部工程師操作、我在旁邊。
5. **不接 on-call。** 我不在他們的值班輪值裡,也不承諾事故處理。(跟正職同時進行時,這條沒得商量。)
6. **時間盒。** 每一段動手參與都有明確的結束日與上限,不做成無限期的人力支援。
7. **只做有架構或流程成分的事。** 修 bug、開發一般功能,請客戶找外包或自己招人。這也是顧問頁 FAQ 寫的原則。

## 跟正職並行要特別注意

- 動手參與比寫報告**更吃即時時間**:code review 要回、pair 要約、CI 壞了要修。先估清楚每週能投入幾小時。
- **production 事故常發生在上班時間**,我沒辦法即時處理。所以不接 on-call,也不當關鍵路徑上的唯一負責人。
- 程式碼、設定、工具**絕不**從正職的工作中複製或改寫。
- 用自己的電腦與帳號,不用公司的設備。

## 計價

- **帶著做**:按天計費,**日費不低於顧問工作的換算日費**,並在提案裡設上限(例如最多 5 天)。
- **實作衝刺**:固定價,估法同 07,但風險係數要拉高(× 1.3–1.5),因為實作會遇到報告階段看不到的細節。
- **兼任**:月費,例如「每月 {4} 天,含非同步 code review 與設計審查」;未用完不累積。

**不要**因為「動手」就降價。你帶來的是資深的判斷力加上執行,不是一般工程師的工時。

## 合約額外條款

在 03 的清單之外,動手參與要多確認:

- [ ] **程式碼的智慧財產權**:付清款項後歸客戶;我既有的工具與通用函式庫仍歸我所有
- [ ] **保固範圍**:交付後 {30} 天內,修正我交付的程式碼中的缺陷;不包含需求變更或環境變化造成的問題
- [ ] **production 責任**:所有部署由客戶審核與執行;對 production 事故的責任以合約金額為上限
- [ ] **權限與資安**:我會拿到哪些權限、如何保管、結案後如何收回
- [ ] **不在值班輪值中**,不承諾事故回應時間

## 提案範本片段

加在 02 的提案裡,當作健檢之後的延伸選項:

```markdown
## 延伸選項:帶著做

報告中的 F1(DAG 冪等化)與 F3(consumer lag 告警),可以由我與 {團隊} 的工程師一起完成第一個:

- 形式:與 {1–2} 位工程師 pair,每週 {2} 個半天,共 {N} 週
- 範圍:{F1 的第一條 DAG},其餘由團隊依照相同做法完成
- 交付:合併進 main 的 PR、設計說明、runbook、一場 walkthrough
- 不包含:production 部署(由團隊執行)、on-call、其他項目
- 費用:NT$ {日費} / 天,上限 {N} 天(NT$ {總額}),實報實銷
```
