# 01 · 初談

目標只有兩個:**弄清楚問題**,以及**判斷我是不是對的人**。30 分鐘,免費,不給解法。

## 收到表單後的回信(2 個工作天內)

```
主旨:Re: [Consulting] {名字} — 關於 {主題}

{名字} 你好,

謝謝你的來信。看了你描述的狀況({用一句話複述對方的問題}),
我想先約 30 分鐘線上聊聊,確認細節,也看看我能不能幫上忙。

以下幾個時段你方便嗎?
- {日期} {時間}
- {日期} {時間}
- {日期} {時間}
(或直接在這裡挑時間:{預約連結})

如果方便的話,會前可以先寄給我:
- 一張大概的架構圖(白板照片也可以)
- 最近最困擾你的一兩個具體狀況

初談不收費,也不需要先簽任何東西。
如果內容涉及敏感資訊,我們可以先簽 NDA 再細談。

Aidan
```

## 初談問題清單

照順序問,不用每題都問到。**多聽少講**,大約 70% 時間是對方在說。

**現況(10 分鐘)**

1. 公司在做什麼?工程團隊多少人、怎麼分組?
2. 這次想處理的問題,用你自己的話講是什麼?
3. 這個問題存在多久了?最近為什麼變得急?(**觸發事件**通常是真正的動機)
4. 目前試過什麼方法?為什麼沒效?

**影響(5 分鐘)**

5. 如果這個問題不處理,半年後會怎樣?
6. 這個問題現在讓你們付出什麼代價?(事故、延遲交付、人力、雲端費用、客戶流失)

**期待(5 分鐘)**

7. 合作結束時,怎樣你會覺得「這筆錢花得值得」?
8. 你們希望我給建議,還是也要一起動手?
9. 誰會決定要不要合作?誰會讀最後的報告?

**條件(5 分鐘)**

10. 希望什麼時候開始?有沒有硬性的截止日?
11. 預算大概在什麼範圍?(表單已填過的話,確認一下就好)
12. 可以讓我看程式碼、監控和雲端後台嗎?需要先簽 NDA 嗎?

**收尾(5 分鐘)**

- 複述一次你聽到的問題與期待,讓對方確認。
- 說明下一步:「我會在 {2–3} 天內寄一份提案,包含範圍、時程和報價。」

## 接不接?判斷清單

**適合接**(大多打勾)

- [ ] 問題落在資料平台 / 後端 / SRE / 團隊運作的範圍
- [ ] 對方有能力執行建議(有工程師、有時間)
- [ ] 決策者有參與,或至少知情
- [ ] 預算與時程合理
- [ ] 我有把握做出對方說的「值得」

**警訊**(任一項都要三思)

- [ ] 與現職公司業務重疊或有利益衝突 → **直接婉拒**
- [ ] 其實是要找人寫功能(外包),不是顧問
- [ ] 希望「保證」某個結果(例如保證不再出事故)
- [ ] 時程是「下週就要」,且範圍很大
- [ ] 決策者從頭到尾沒出現
- [ ] 一直要求先免費看一下系統、先給點建議

## 婉拒範本

```
{名字} 你好,

謝謝你花時間跟我聊。仔細想過之後,我覺得這個案子{不是我最能幫上忙的類型 /
時程上我沒辦法給到足夠的投入},為了不耽誤你們,這次我先不接。

{如果有:我認識的 {人名} 在 {領域} 很有經驗,需要的話我可以幫你們介紹。}

祝一切順利,之後如果有其他問題,也歡迎再來信。

Aidan
```
