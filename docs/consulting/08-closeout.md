# 08 · 結案

結案的目的除了收尾款,還有**留下下一個案子的素材**:推薦、案例、教訓。

## 結案信(交付後 1–2 天)

```
{名字} 你好,

{專案名稱} 到這裡告一段落,謝謝你們這 {N} 週的配合。

回顧一下交付內容:
- {報告名稱}(已寄出 / 連結)
- {說明會日期}的簡報與錄影
- {其他交付物}

接下來 {2} 週內,有任何關於報告的問題都歡迎直接來信。

尾款的請款資料附在這封信裡,麻煩在 {日期} 前處理。

最後想請你幫兩個小忙(都可以拒絕,不影響任何事):
1. 花 3 分鐘填一下回饋問卷:{連結}
2. 如果覺得這次合作有幫助,可以給我一兩句推薦嗎?
   我會放在網站上,放之前會先給你確認文字與署名方式。

Aidan
```

## 回饋問卷(5 題以內)

1. 整體來說,這次合作對你們有多少幫助?(1–10)
2. 最有價值的是哪個部分?
3. 有哪裡可以做得更好?
4. 你會推薦給其他團隊嗎?為什麼?
5. 可以把你的回答(或部分內容)放在網站上嗎?署名方式:
   □ 全名 + 職稱 + 公司  □ 職稱 + 公司規模/產業  □ 匿名  □ 不公開

## 推薦文字的引導

直接請人寫推薦,對方常常不知道寫什麼。可以給個方向:

> 可以簡單說說:合作前遇到什麼問題、合作過程中印象最深的一件事、
> 合作之後有什麼改變?兩三句就夠了。

## 案例授權

想把案子寫成部落格文章或放在顧問頁時,**一定要先取得書面同意**(email 即可),並且:

- 去除可識別的細節(公司名、產品名、具體數字),除非對方同意公開
- 寄草稿給對方確認後才發布
- 已簽 NDA 的案子,以 NDA 的條款為準

## 內部回顧(給自己,放在私人的地方)

```markdown
## {案子} 結案回顧 — {日期}

- 報價 / 預估時數 / 實際時數 / 實際時薪:
- 範圍有沒有膨脹?怎麼發生的?下次怎麼避免?
- 客戶最在意的是什麼?跟我以為的一樣嗎?
- 哪個範本不好用,要改什麼?→ 回頭更新 docs/consulting/
- 有沒有可以寫成文章的主題(去識別化後)?
- 90 天後要追蹤嗎?日期:
```

## 90 天後追蹤

```
{名字} 你好,

距離 {專案名稱} 結束已經三個月了,想問問報告裡的建議後來進展如何?
有沒有遇到新的問題?

純粹關心,不是推銷 :) 有需要的話隨時可以聊聊。

Aidan
```

這封信的回覆率通常很高,也常常是下一個案子的開始。
