# 07 · 定價試算

> 這份只放**方法**。實際的價格、調價紀錄、每個案子的工時,放在私人的地方。

## 第一步:算出你的目標時薪

```
目標時薪 = 你希望這份副業每年帶來的收入 ÷ 一年實際可以接案的時數
```

- 可接案時數要**扣掉業務與行政時間**:初談、寫提案、談合約、開單據、追款。
  剛開始時,每 1 小時的交付大約還要花 0.5–1 小時在這些事上。
- 顧問的時薪通常是**同等級正職時薪的 2–3 倍**,因為:
  沒有年終、勞健保與退休金、案源不穩定、還要負擔業務時間。

## 第二步:換算成固定價格

```
報價 = 預估交付時數 × 目標時薪 × 風險係數
```

| 因素 | 係數 |
|---|---|
| 範圍清楚、做過類似的案子 | × 1.0 |
| 第一次做這類案子 | × 1.2–1.3 |
| 範圍模糊、系統很大、對方反應可能很慢 | × 1.3–1.5 |

**預估時數的參考**(依經驗修正)

| 服務 | 交付時數 |
|---|---|
| 單次諮詢 60 分 | 會議 1 + 會前準備 0.5–1 + 會後整理 0.5–1 |
| 架構健檢(標準) | Kickoff 1 + 資料檢閱 8–12 + 訪談 4–6 + 分析 8–12 + 報告 8–12 + 說明會 2 + 問答 2 |
| 陪跑(每月 4 次) | 會議 4 + 準備與紀錄 2–3 + 非同步問答 2–4 |

## 第三步:檢查合理性

- **對客戶的價值**:這個問題每個月讓他們付出多少?(事故處理時數 × 工程師時薪、雲端費用浪費、延遲交付的機會成本)
  報價在一年價值的 **10–20%** 以內,通常很好談。
- **跟市場比較**:問問做過顧問的朋友,或看公開的顧問報價。
- **跟自己比較**:如果這個價格讓你覺得「有點心虛」,多半是剛好;如果覺得「很輕鬆」,可能太便宜。

## 剛起步的做法

- 前 2–3 個案子可以打折換取**推薦與案例授權**,在提案裡寫明原價與折扣:
  「原價 NT$ X,首批客戶優惠 NT$ Y,條件是結案後提供一段推薦。」
- **不要**用低價當作長期策略。低價吸引的客戶通常要求最多。
- 每完成一個案子,**記錄實際花的時數**,跟預估比較,修正下一次的報價。

## 什麼時候漲價

- 詢問量多到接不完
- 連續幾個案子,客戶都沒有對價格有任何反應
- 你的交付變快了(同樣的價值,花更少的時間)

漲價只對**新客戶**生效;既有的陪跑客戶,提前一個月通知,下一季才調整。
